## Mission

KeyShot-simple OSS product renders in Blender. Best Blender plugin for product rendering and production workflows under **BEHOLD by AMIRITE.studio**.

Cadence: one focused feature cut, then a GitHub Release. Do not kitchen-sink.

## Implemented

- **Light & shadow linking lite (0.21.0)** — point-and-toggle include/exclude for the active BEHOLD light against selected objects (Cycles light linking). Compact Lights card: **Light / Shadow**, **Link Selected** (Wrangler L cycle: include → exclude → unlink), **Unlink** (selection, or clear if nothing is selected), **Solo product** (include only the product; cyclorama stays unlit). Maps to Cycles `Object.light_linking.receiver_collection` / `CollectionObject.light_linking.link_state`. Shadow linking uses `blocker_collection` when that RNA is present (stable on 5.2). Missing engine or API reports a sentence + next step (`NO_LINKING_ENGINE`, `NO_LINKING_API`, `NO_SHADOW_API`). Empty Lights state unchanged. Tests in `tests/test_light_linking.py`. Not gobos / IES / logo / Wrangler gizmos.
- **Compositor look pack (0.20.0)** — one-click still looks on the compact Shoot **Look** card: **Clean**, **Catalog**, **Dramatic**. Maps to compositor nodes BEHOLD builds and tears down (`BEHOLD_Look*` prefix; `nodes.clear()` when the tree is ours). Catalog = mild vignette + grain + contrast, glare off (bloom-safe). Dramatic = stronger vignette/grain plus mild Fog Glow (`mix` still negative). **Compositor** toggle disables and restores a clean still. Custom compositor trees report a sentence + next step (`LOOK_COMPOSITOR_BUSY`) instead of being overwritten. Empty/error copy stays sentence + next step (`NO_COMPOSITOR`, `UNKNOWN_LOOK_PRESET`). Apply Look stays in Advanced. Tests in `tests/test_looks.py`. Not gobos / IES / logo.
- **Catalog batch export (0.19.0)** — compact **Batch export** on Shoot. One click renders stills for **Front / ¾ / Top** and/or **Saved shots** from Shot Manager. Output folder tokens `{angle}` `{camera}` `{quality}` (angle is the catalog slug or a shot-name slug). Progress reports `Batch n/total: …`; failures stay sentence + next step (`BATCH_NOTHING`, `BATCH_NO_MESH`, `BATCH_NO_SHOTS`). Restores camera pose and scene look after the run. Elevates the old Advanced `batch_angles` control. Tests in `tests/test_batch.py`. Not gobos / IES / logo.
- **Bake studio to HDRI (0.18.0)** — compact **Bake HDRI** on Studio. Cycles equirectangular render of BEHOLD lights (meshes hidden) to `.exr` / `.hdr`. **1K** (1024×512) / **2K** (2048×1024). Empty path → next to the `.blend` or temp. Optional **Include world**. Optional **Apply after bake** loads the map as the scene world (does not auto-mute lights). Empty/error copy stays sentence + next step (`NO_LIGHTS_TO_BAKE`, `NO_BAKE_PATH`, unsupported `.png`). Tests in `tests/test_bake_hdri.py`. Not gobos / IES / Shot Manager / logo.
- **Physical exposure polish (0.17.0)** — Photographer-class lite on Shoot. Compact **Look**: EV (−6..+6), Kelvin white balance (D65 6500 K), AgX-safe **False Color**. Live RNA updates push `scene.view_settings` (viewport + render). 5.2 uses `use_white_balance` + `white_balance_temperature`; older builds fall back to a D65 temperature offset. False Color remembers the previous view transform instead of always forcing AgX. Empty/error copy stays sentence + next step (`FALSE_COLOR_UNAVAILABLE`, `NO_VIEW_SETTINGS`). Apply Exposure remains in Advanced; Light Draw **F** still toggles False Color. Tests in `tests/test_exposure.py`. Not Shot Manager / gobos / IES.
- **Light shaping lite (0.16.0)** — one-click area looks on the active BEHOLD light: **Softbox**, **Strip**, **Octa**, **Hard**, **Rim**. Maps to Cycles area RNA (`shape` / `size` / `size_y` / `energy` / `spread`). Softbox / Strip / Octa get a procedural emission falloff (Texture Coordinate → Gradient → ColorRamp → Emission); Hard is uniform with tight spread. Empty Lights state unchanged. **Apply to active** (adds a light only when the inventory is empty). Not gobos / IES. Tests in `tests/test_light_presets.py`.
- **Test hardening + draw-pass cache (0.15.0)** — no new artist features. Regression coverage for HDRI path/graph helpers, cyclorama fit edge cases (NaN headroom/extents, bevel, XY floor edge), update semver compare (`v`/`rc`/`+build`/four-part), and Import Product dispatch (every registered extension, dotted names, unknown). N-panel draw: `cad_status()` (addon_utils / bl_ext walk) and scene product/studio/look/camera flags run **once per UI pass** (`behold/draw_cache.py`, `cad_status_for_draw`, `scene_snap_from_context`) instead of once per sibling panel. Turntable empty-state uses the snap, not a `product_targets` list. Operators still call fresh `cad_status()` after enable. `make test` stays offline. Does not change Shot Manager (already on `main` as 0.14.0). Tests in `tests/test_draw_cache.py` plus expansions in `test_hdri_world.py`, `test_studio_fit.py`, `test_updates.py`, `test_formats.py`, `test_mesh_invoke.py`.
- **Shot Manager (0.14.0)** — named shoot presets on Shoot (KeyShot Studios–skinny, not a clone). A Shot stores active/bookmarked camera name, render quality, turntable seconds, HDRI path/strength/rotation (plus reflections-only / background when present), backdrop tone, and output path tokens. **Add** from current, **Apply** restores camera + `scene.behold` + world HDRI without touching the product mesh, inline rename, Delete. Empty state until the first shot. CollectionProperty on the scene — survives save/reload. Tests in `tests/test_shots.py`.
- **Brand + HDRI world (0.13.0)** — official mark (`behold/icons/behold_icon.png`) loaded with `bpy.utils.previews` on register: N-panel hero, main header, preferences branding, pie / header trigger. Studio compact HDRI: Load (HDR/EXR/OpenHDRI disk file) into the world environment texture, strength, Z rotation (degrees), optional **Reflections only** + camera **Background** strength (Light Path mix, Cycles/EEVEE), **Reset world** to solid studio. Build Studio keeps a loaded HDRI. Errors share `behold/ui/messages.py`. Leveling path: [ROADMAP.md](ROADMAP.md).

## First-ship chrome (Percival)

N-panel keeps the three-click path skinny, but **physical order matches the work**. Lights, Materials, and Cameras sit between Studio and Shoot so artists do not scroll past Shoot to dress, then back. Turntable stays a compact row on Shoot — not a fourth first-class section. v0.9.0 is Percival chrome (hero, flow strip, cards, pie/header); v0.10.0 adds the update notice; v0.11.0 is cyclorama auto-fit (order already shoot-path); v0.12.0 is Percival `bl_order` + error copy; v0.13.0 is official mark + compact Studio HDRI; v0.14.0 is compact Shot Manager on Shoot; v0.15.0 is test/opt only; v0.16.0 is Lights shape presets; v0.17.0 is compact Look (EV / WB / False Color) on Shoot; v0.18.0 is compact Bake HDRI on Studio; v0.19.0 is compact Batch export on Shoot; v0.20.0 is compositor look presets on the same Shoot Look card; **v0.21.0 is compact Linking on Lights** — not a new mega-panel.

1. **Import** — **Import Product** file picker + one CAD backend line (**STEPper NEXT ready** / **OCP fallback** / **Install STEPper NEXT**). Auto-studio, Material Assist toggle, and the full CAD box stay in Advanced. Do not embed STEPper's import dialog.
2. **Studio** — backdrop **White / Grey / Black** + one **Build** button, compact **HDRI** card (Load / Reset, strength, Z rotation, optional reflections-only), compact **Bake HDRI** (1K/2K, path, Include world, Apply after bake). No light mixer. Cyclorama auto-fits; **Studio Margin** stays in Advanced.
3. **Lights** — inventory + Light Draw Active / New + **Shape** row (Softbox / Strip / Octa / Hard / Rim) and **Apply to active**, plus compact **Linking** (Light / Shadow, Link Selected / Unlink / Solo product). Empty state unchanged. Not a Light Wrangler clone; native Blender chrome.
4. **Materials (0.8.0)** — local rack + Assist. Empty state if no product mesh is selected. Not a BlenderKit browser. Flow-strip **Dress** Next = Assist.
5. **Cameras** — inventory + Add / Frame / Clear. Not Blender's Properties camera dump; native BEHOLD chrome.
6. **Shoot** — **Draft / Final**, **Still**, **Render**, compact **Look** (EV / Kelvin WB / False Color, Clean / Catalog / Dramatic + Compositor toggle), compact **Shots** (list / Add / Apply / rename / Delete), compact **Batch export** (Front / ¾ / Top and optional Saved shots), compact **Turntable** (seconds + Setup / Play). Last first-class section. Path token picker, camera bookmark, turntable bake, and ease stay off this panel.
7. **Main shell (0.9.0)** — `BEHOLD_PT_main` draws the hero + flow strip. Child panels keep `draw_header` icons and `bl_order`. **0.10.0** adds a dismissible update notice on the main panel when a newer stable zip is cached — not a new first-class section.
8. **Advanced** (`BEHOLD_PT_advanced`, `DEFAULT_CLOSED`) — mixer, **Studio Margin**, CAD box, BlenderKit login/search/apply, Light Draw hotkeys, output folder tokens, turntable spin / bake / clear / render, Bookmark / Use Main. Look sliders + Apply Exposure / Apply Look and Batch export toggles stay as parked duplicates of Shoot.

Backend operators stay registered. Pie / header / preferences do not replace the N-panel path.
