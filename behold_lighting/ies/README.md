# BEHOLD IES samples

Tiny photometric files that ship in the add-on zip. **Bring your own `.ies`**
for a real fixture — this is not a manufacturer catalog.

| File | What it is | License |
| --- | --- | --- |
| `sample_spot.ies` | Original axially-symmetric downward practical (Type C, meters, absolute photometry). Written for BEHOLD so artists can try Load without hunting a file. | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

Not copied from a vendor IES library. Production stills should use the maker’s profile.
